Publicar no canal Touchpoints

Isto vai para o cliente. A mensagem é publicada no canal Touchpoints do ClickUp, que os clientes leem. Não há desfazer pela tela — apagar depois é na mão, no ClickUp.
Para confirmar, digite PUBLICAR
A tela não registra o envio em banco — mb_touchpoints não existe ainda. O controle de "já enviei esta semana" mora neste navegador, e é por isso que a confirmação é digitada.

Corrigir números —

Isto conserta o bloco, não o cadastro. A correção vale para esta semana, neste navegador: o Supabase continua com o valor antigo, e sem alguém arrumar a origem a mesma correção volta na semana que vem. O bloco corrigido é reescrito pela régua na hora — e o cenário não é reclassificado sozinho, por isso ele está aqui embaixo para você escolher.
Por que o número do banco está errado? obrigatório — vai para o CS e para o CSV, nunca para o cliente

Enviar para CS

Vai para a conversa privada da CS no ClickUp — pela conta que assina o token do n8n, então para quem recebe é um DM dessa pessoa, não de um robô. O canal Touchpoints não recebe nada por aqui: são caminhos separados, e enviar para a CS não conta como semana publicada.

Token compartilhado
Tem de bater com o campo token do node Config dos três workflows. Não é autenticação forte, e é o que separa esta página pública dos dados dos clientes.
Canal de ensaio (opcional)
Com um id aqui, o diálogo de publicar ganha a opção ensaio: a mensagem sai de verdade, mas nesse canal em vez do Touchpoints. É onde dá para clicar em Publicar sem cliente vendo. Vazio = só o canal real.
